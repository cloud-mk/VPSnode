# v0.1.11 实际验证范围

日期：2026-11-21，Asia/Shanghai。基线：公开版 v0.1.10。环境：Windows 10 IoT Enterprise LTSC x64（19044），.NET SDK 10.0.404，现有 v2rayN 中的 Xray。所有本轮公开测试数据为 RFC 5737 示例地址、example.org 域名、虚构身份或隔离回环服务；生产台账和外部 VPS 未改动。

## 自动化与实际进程：已通过

Release 构建 0 警告、0 错误。10 套测试通过：Smoke、BackupTests、IdentityTests、InventoryChecks、UiBatch、FormTests、UiRegression、StabilityTests、AgentTests、ProxyUiTests。测试均使用独立数据目录。

- **AgentTests：89 项检查**。启动真正的 CLI 子进程和独立 worker，覆盖 JSON/退出码、资产增改删、SSH 凭据保护、字段清空/false/空数组、修订冲突、非法输入、配置默认遮罩及显式查看、来源同步、备份预览/恢复、任务历史、排队取消、无 GUI 执行、真实回环 SSH 失败、HTTP/HTML title 及 TLS 失败区分。模拟中断记录只用于补充边界；真正进程被终止的恢复由下一套验证。
- **ProxyUiTests：实际 Xray 回环**。独立 VLESS 服务和受限 HTTP origin；单节点和全库延迟/下载均到达服务端，下载按字节上限截断。测试期间修改窗口尺寸，保持页、行、手调列宽和选择不变。实际 HTTP 失败、取消和 18 秒请求超时保留正确终态。
- **实际跨进程闭环**。GUI 存在但其 tick 停止时，CLI worker 独立完成真实延迟/下载；提交可及时返回，重复活动请求复用 ID。查询持久 running 进度，等待超时不取消任务，GUI 取消 CLI worker，CLI 取消 GUI 正在执行的任务，排队任务可取消。
- **真正执行进程中断**。读取任务记录的 executorPid，并确认进程路径为本测试 CLI 后终止它及其子进程。下一次 task wait 将原任务标为 failed / executor_interrupted，没有假成功或永久 running。
- **真正 TLS 握手**。现有 Xray 在回环端口呈现内存生成的虚构过期证书；CLI check tls 实际采集到已过期及真实 NotAfter。未把“探测失败”当作“已验证证书过期”。
- **WPF 状态与统计**。超过旧阈值的 SSH、节点、网站与 TLS 成功仍为成功并使用正常颜色；检测时间保留。节点可用数和总览异常筛选包含旧成功结果，仍排除暂停和入站/客户端禁用。真实到期依旧显示“证书已过期”；原始 State 和 At 不改写。
- **共享表格与既有功能**。总览、VPS、网站及任务等共享 DataGrid 在两种主题验证相邻表头细线、无数据竖线、原生拖宽热区和同结构列宽协调。节点页保留 0.1.10 原位更新、宽度/列序/水平滚动同步、筛选/导航后的宽度，以及重复核对窗口复用与生命周期。WPF 100/150% 图像仅为渲染比例，不能代表物理 DPI 切换。
- **备份与关联**。旧备份全量往返、错误口令无写入、ID/身份冲突、关联快照和来源/历史保留回归通过。新任务回执随同一加密资产容器恢复，不另建备份系统。

## 真正 Windows 桌面操作：已通过的具体范围

通过 computer-use 操作独立数据目录下的真正 VPSnode.exe，与独立 CLI 共享数据库；不是把进程内 RaiseEvent 冒充鼠标。

1. CLI 录入两台虚构 VPS、节点及网站，GUI 实际显示；CLI 修改节点名称后自动刷新。
2. CLI 新增节点，GUI 显示新增行；CLI 删除后，该行实际消失。
3. 在真实 GUI 打开节点编辑窗口，用鼠标取消“手动暂停巡检”并保存；独立 CLI 读到 paused=false、manual=true。
4. 鼠标拖动总览表头，两组同结构表的边界实际同步，数据行无竖线。
5. 查看代理节点、VPS、网站和证书视图，切换浅/深色；共享表头显示一致。鼠标切换深色后，CLI 读到已保存主题。
6. CLI 提交暂停节点检查后，真实 GUI 显示最近任务计数；通过设置里的“退出应用”退出独立测试进程。

自动化工具的 accessibility 索引在本机失效，采用重新观察后的截图坐标操作；模态编辑框的键盘文字输入未生效，**没有记为通过**。上面的节点业务修改由实际鼠标勾选和保存完成，CLI 回读已独立核对。没有为此改用自建 UI 自动化或跳过校验。

正式包应来自 v0.1.11 标签的 GitHub Windows 构建；正式发布前核验下载附件 SHA-256、版本/源码提交、MSI 管理解包与 ZIP 文件一致性、独立 CLI 及桌面启动。最终 Commit、CI、Tag、附件校验和核验结果见 [该版本 Release](https://github.com/cloud-mk/VPSnode/releases/tag/v0.1.11)。本节描述发布核验门槛，不把编译或源码测试当作发行包验证。

## 未验证或保留限制

- 没有登录生产 VPS，没有测试公网多协议速度、外网 SSH 成功盘点和 REALITY 三条公网路径；这些沿用现有检测实现，不能用本机样例宣称公网通过。
- 干净系统安装/升级/卸载、跨电脑与跨 Windows 用户恢复、物理 DPI/多显示器迁移、长期连续运行、Windows 通知实际送达仍未完成现场验收。
- 模态框真实键盘文字输入如上未通过工具验证；不能把表单进程内测试写成该项通过。
- CLI worker 是短生命周期执行进程；定时巡检和来源自动跟随仍由运行中的 GUI 触发。只读 task get 不恢复中断任务；worker、task wait 或 GUI tick 执行恢复。升级前需退出旧版托盘进程。
- 历史保留、查询上限、部分成功/跳过和终态退出码见 [Agent 契约](agent-cli.md)。同 ID 的导入合并不等同于显式字段编辑。
- 包保持未签名。已有旧版本曾经丢弃的配置无法追溯恢复。

这些限制没有被标记为通过。完整业务对应和修改位置见 [覆盖矩阵](coverage-0.1.11.md)。
